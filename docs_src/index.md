A simple application launcher that aims to stay small and efficient.

## Built With

Feather is written in [Gossamer](https://github.com/gossamer-lang/gossamer) on
the [gui-gos](https://github.com/gossamer-lang/gui-gos) toolkit, built on a core
of [Rust](https://rust-lang.org/) and [SDL3](https://github.com/libsdl-org/SDL).
